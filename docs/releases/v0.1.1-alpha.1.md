# Context Relay 0.1.1 — Windows Preview

An unsigned Windows x64 preview for shared encrypted memory and tasks across
Claude Code, Codex and Hermes. Windows 11 24H2 or newer is the preview target.
Only harness versions qualified in the adapter capability pages support managed
setup; unsupported versions remain import-only.

The preview includes local memory and task management, reviewed harness setup
and Undo, and hosted sign-in, pairing, synchronization and recovery after the
release acceptance checklist is completed. This file is prepared release copy,
not evidence that those gates have passed.

## Installation and updates

Download the NSIS setup executable and compare its SHA-256 with SHA256SUMS.
The installer is not Authenticode-signed; Windows may show an unknown-publisher
or trust prompt. Obtain the executable only from this repository's release.

Updates are manual. There is no automatic updater. Preserve your recovery
material and encrypted data before updating; never delete the installation
directory as a rollback procedure because it may contain the vault.

## Preview limits

macOS, repository/package installation, activity history, and automatic updates
are not included. Paid signing and optional dependency upgrades are deferred.
Do not use the preview as the sole copy of irreplaceable information.

provenance.json identifies the source commit, workflow, hosted configuration
fingerprint, binary/resource hashes and build tools. sbom.cdx.json inventories
the Windows-filtered Rust and installed Node build dependencies; provenance
separately inventories packaged resources. No credentials are included.

## Maintainer publication gate

Before approving the windows-preview-publication environment, verify that the
candidate run was dispatched on main, the protected v0.1.1-alpha.1 tag names its
source SHA, and the supplied installer digest is exactly the installed/hosted
acceptance candidate. Review the completed readiness report, license inventory,
clean-OS and N-1 acceptance, current CI and remaining limitations.

The workflow refuses another tag/source/run/digest and uploads the accepted
bytes without rebuilding. Do not reuse or move v0.1.0-alpha.1.
