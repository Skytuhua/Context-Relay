# Context Relay

## Platform
web

React frontend packaged as a Windows/macOS Tauri desktop application.

## Audience and purpose
People using Codex, Claude Code or Hermes who want decisions, preferences and
project facts available in later harness sessions without repeatedly explaining them.
Assume familiarity with their harness, not with terminals, configuration files, MCP,
hooks, encryption internals or Context Relay's architecture.

## First value
Choose a harness and project, approve its connection setup, save a useful note and
see the harness retrieve that note. Never substitute a service health check for this.

## Product register
Product tool. Compact, efficient, clean and clear; charcoal with restrained orange
actions. Labeled controls, useful density and predictable interactions. Dark default;
Light/System available. Existing records and exact setup Undo/recovery are preserved.

## First launch
Guided harness selection, deliberate project selection, connection, real note test,
then a short dashboard tour. Finish later/resume and Help replay are always available.
Explain what each feature does, why it matters and its next action. Keep essential
instructions visible; reserve Advanced details for paths and implementation details.
